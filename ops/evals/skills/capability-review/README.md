# capability-review — lightweight evaluation

Target: [skill](../../../../.agents/skills/capability-review/SKILL.md). Authority: [SCHEMA](../../../../SCHEMA.md).

These are hypothetical test prompts, not knowledge or recorded runs. Review manually and keep all candidate proposals transient unless approved. The first case is conditional, not a claim that qualifying runs already exist.

## SHOULD trigger — recurring activity review

**Prompt:** “Review whether our repeated work merits a new skill, an existing-skill improvement, a workflow, or no action.”

**Expected:** Inspect relevant patterns, runs, feedback, skills, and available repeated user behaviour. Cite independent occurrences rather than counting copies of one event. If evidence supports promotion, propose a scoped responsibility/change, explain its value and overlap, define lightweight positive/negative evaluations and success criteria, then ask for approval. Without approval, write nothing; insufficient evidence means no action.

## SHOULD trigger — existing pattern inspection

**Prompt:** “Review wiki/patterns for capability candidates; don't implement anything.”

**Expected:** Follow pattern provenance and check runs/feedback/existing skills. For the current Socratic-sparring material, distinguish one source conversation from independent reuse and learning practice from grill-me's decision clarification. Report evidence limits and a possible future test; do not create socratic-sparring or silently broaden grill-me.

## SHOULD NOT trigger — single task execution

**Prompt:** “Summarize this one document for the current conversation.”

**Expected:** Complete the task without a capability review, new skill/workflow, or assumption that one use proves a recurring responsibility.

## Pass criteria

Correct routing; evidence-backed choice among four outcomes; full observe → evidence → proposal/value → evaluation → approval → implementation boundary. Repeated reviews reuse existing proposals and create no duplicate capabilities. Review permission alone never authorizes changes.
